# Profile Card

A simple profile card project built using **HTML and CSS**. It presents personal information, skills, and profile actions in a clean and visually appealing layout.

## Features

- Profile image and introduction
- About section with personal details
- Skills section
- Profile and contact buttons
- Custom background styling
- Responsive layout

## Tech Stack

- HTML5
- CSS3

## Project Structure

```text
Profile-Card/
├── index.html
├── style.css
└── images/
    ├── profile.jpg
    └── background.jpg
```

## Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser to view the profile card.

## Purpose

This project focuses on practising HTML structure, CSS styling, layouts, images, and responsive design.
